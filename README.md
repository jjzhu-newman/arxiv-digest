# 工作日 arXiv 导读

这是一份面向凝聚态与量子方向的个人阅读笔记，按工作日收录：

- `YYYY-MM-DD/report.md`：当日兴趣摘要（中文）
- `YYYY-MM-DD/final_picks.json`：入选论文的结构化记录
- `YYYY-MM-DD/arxiv-jingdu-YYYY-MM-DD.pdf`：精读卡合集（通常在摘要之后的早晨生成）

扫描范围包括 `cond-mat`、`quant-ph`、`hep-th`、`math-ph`，以及 `cs.LG` / `stat.ML` 中偏物理信息或量子的条目。兴趣锚点大致是：非厄米拓扑与开放系统、交错磁与自旋电子学、纠缠与量子关联、Floquet 系统、物理信息神经网络与神经网络量子态、量子机器学习，以及量子传感。

工作日午夜左右更新摘要，早晨更新精读卡。arXiv 因假期顺延公告时，当天可能只有空窗说明、没有新的入选或精读卡。论文版权仍归原作者，请以 [arXiv](https://arxiv.org) 原文为准。
